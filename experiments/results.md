# chunk 参数对比实验报告

- 实验时间：2026-09-15 21:02
- 语料：data/ 下 3 篇文档（尺码推荐 / 洗涤养护 / 颜色选择）
- 评估集：16 道题（含大量换述题，考语义检索而非字面匹配）
- 嵌入模型：BAAI/bge-m3（经 SiliconFlow API）
- 指标：hit@1 = 检索第一名命中正确文档的比例；MRR = 排序质量
